CHANDRA SHUM SHERE MANUSCRIPT CATALOGUE

Static site for https://suhasmahesh.com/oxford-css-manuscripts/.
All assets use relative URLs; no CNAME is needed for the project repository.
GitHub Pages publishes the main branch root. .nojekyll disables Jekyll.

All 690 folio photographs are bundled with this site. The original photographs
are 2,691 pixels high and have not been rescaled or recompressed. Entry crops use
the same files, with proportional native-coordinate locations. Higher-resolution
Bodleian images are available only through explicit links opening another tab.
No remote images, fonts, analytics or APIs load automatically.

The startup index contains all 13,028 records and their filter/sort metadata.
Full records and folio notes load from versioned data/records bundles as needed.
The full-text search index loads only when a query is entered. Downloads and
spreadsheet sorting wait for all relevant complete records. This split changes
delivery only: readings, classification evidence, audit files and source images
are preserved. The catalogue can also be opened locally using index.html.

Source: Bodleian Libraries, MS. Chandra Shum Shere c. 484.
Machine transcription without human editing; uncertain readings remain marked.
The images retain their original attribution. No additional licence is asserted.
